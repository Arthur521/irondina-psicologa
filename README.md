# Psicóloga Larissa

Site institucional e biblioteca de artigos da Psicóloga Larissa Caramaschi.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

O catálogo em `src/data/articles.json` contém os 61 artigos públicos mapeados a partir do site de referência, com seus links canônicos preservados.
